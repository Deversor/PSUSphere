# PSUSphere - Student Organization Management System

This project is a Django-based web application for managing student organizations, members, and academic programs at PSU.

## Features
- **Automated Data Generation:** Uses the Faker library to populate the database with realistic Philippine-based student records.
- **Refactored Admin Interface:** Advanced search, filters, and custom column displays for better data management.
- **Relational Database:** Tracks Colleges, Programs, Students, and Organization memberships.

## Installation
1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`
4. Run migrations: `python manage.py migrate`
5. Start the server: `python manage.py runserver`
